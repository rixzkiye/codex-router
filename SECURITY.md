# Security Policy

## Supported versions

Codex Router is pre-1.0. Security fixes are applied to the latest release on the `0.1.x` line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's private vulnerability reporting form under **Security → Advisories → Report a vulnerability**.

Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Please avoid including live credentials, private source code, or production data. You should receive an initial response within seven days.

The project will coordinate disclosure after a fix is available. If private vulnerability reporting is unavailable, open a minimal public issue asking the maintainer for a private contact channel without disclosing vulnerability details.
